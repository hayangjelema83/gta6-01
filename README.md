# Solmar City — open-world crime game (make.fun gta6-01)

An original open-world crime game that runs in a desktop browser from static files: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, run missions.

Built for the make.fun GTA 6 bounty. All city, characters, vehicles, names, story, art and sounds are original — no Rockstar Games assets.

Play it: serve `game/` with any static HTTP server and open `game/index.html`.
